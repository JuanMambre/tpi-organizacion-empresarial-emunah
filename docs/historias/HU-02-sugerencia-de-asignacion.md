# HU-02 · Sugerencia de asignación de tickets
> **Como** coordinador de desarrollo, **quiero** recibir una sugerencia de desarrollador para cada ticket nuevo, basada en su experiencia en el módulo afectado y en su disponibilidad, **para** asignar el trabajo con mejor criterio y distribuir el conocimiento del equipo.

Criterios de aceptación:
- Se genera una sugerencia para al menos el 90 % de los tickets con información suficiente (Meta 3).
- El coordinador puede aceptarla o rechazarla; si la rechaza, se registra el motivo.
- Al asignar, se alerta si hay tickets relacionados en curso sobre el mismo componente (Meta 4).

**Tablero:** issue vinculado en GitHub Projects · estados *Por hacer → En progreso → Listo*.
